🛠️ HOW TO RUN LOCALLY:

Step 1: Install Node.js
- Download from: https://nodejs.org
- Install the LTS version

Step 2: Open Terminal in Project Folder
- Navigate to the folder containing these files
- Or: Right-click inside the folder → "Open in Terminal"

Step 3: Install Dependencies
Type: npm install

Step 4: Start the Server
Type: node server.js

Step 5: Open Browser
Go to: http://localhost:3000

🔑 API KEY NEEDED:
- Get a free API key from: https://openweathermap.org/api
- In server.js, replace YOUR_API_KEY with your actual key
- OR set it as an environment variable: process.env.API_KEY
